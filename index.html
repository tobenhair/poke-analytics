File Format Guide

Your .xlsx file must contain exactly two sheets named Summary and Historical Data. Column names must match exactly (case-sensitive).

Sheet 1 — Summary

One row per product. Each row becomes an entry in the main table.

How the fair price works

In one paragraph, so you can judge how much to lean on it.

The method

Sealed product tends to lose value density as it ages. So the app fits a straight line through every tracked product — SV/Booster against age — and reads off the value a product of this age would be expected to have. Turn that expectation back into euros and you get the fair price: what this product would cost if it traded like its same-age peers. Under it is cheap for its age; over it is expensive.

How confident it is

The line never fits perfectly, and how well it fits is what the confidence word tells you. Strong fit — age explains most of the variation, so the fair price is a firm number. Moderate fit — a reasonable guide, not a valuation. Rough estimate — age explains little here, so the fair price is greyed out and the buy/avoid verdict ignores it entirely rather than pretending. The underlying statistic (R²) is on each product's drill-down.

A fair price is a comparison with the rest of the catalogue, not a valuation or a price forecast. It moves as the catalogue moves.

What the numbers mean

Every term on the board, defined once.

Set Value The total market value of all the cards in a complete set — what the product is a lottery ticket for.
Price / Booster The product price ÷ the number of boosters inside — set by Type (BOX = 36, ETB = 9, BUNDLE = 6, and the variants ETB10 = 10, ETB8 = 8, BUNDLEDISPLAY = 60, PACK = 1). Puts a €58 bundle and a €400 box on the same footing.
SV / Booster Set Value ÷ Price/Booster — how many times the price of a single booster the whole set is worth (a value-for-money × multiple, not a euro amount). The core comparability metric; works equally well across every product type, from a single pack to a booster box.
Age Weight A penalty applied to newer products, which haven't had time to appreciate. Adjustable with the age-threshold slider on the Analysis tab.
Wtd. Score SV / Booster × Age Weight. The ranking metric behind the board's default order.
Fair Price What this product would cost if it traded like its same-age peers — the age fit read back into euros. Under it is cheap for its age, over it is expensive.
Fit confidence Strong fit, moderate fit or rough estimate — how well age explains value across the catalogue right now, and so how far to lean on the fair price. On a rough estimate the verdict ignores it entirely.
Verdict The board's one-line answer per product, from the gap to fair price plus how far the price has fallen from its tracked peak — Under fair price, Fair — no edge, Overpriced for age, and so on.
Buy Signal Flagged when a product's price dropped at least 5% since the last snapshot while its set value held within ±5% — a possible mispricing.
Every figure is in EUR and comes from prices entered by hand, one snapshot at a time. Nothing here is financial advice.

Sealed Analytics

Finding great products at fair prices

Is this sealed box fairly priced?

That is the one question this dashboard answers. It tracks sealed Pokémon TCG products — booster boxes, Elite Trainer Boxes and bundles — and weighs what each one costs against the set value behind it: what a complete set of the cards inside is worth. Prices are entered by hand, one month at a time, so every number has a dated history behind it.

How to read it

1Value, not price

A €180 box is neither cheap nor expensive on its own. Divide the set value by the price of one booster and you get SV/Booster — how many times a booster's price the whole set is worth. That single figure compares a €58 bundle with a €400 box directly.

2Age moves the bar

Sealed product tends to lose value density as it ages, so a three-year-old box and a three-month-old one can't be judged against the same number. The dashboard fits a line through every tracked product — value density against age — and measures each one against its own age.

3The verdict

Read that expectation back into euros and you get the fair price: what this product would cost trading like its same-age peers. The board says which side of it you're on, in words — Under fair price, Fair — no edge, Overpriced for age — and how far to trust the fit.

      Value Over Time

      What: what your current holdings would have been worth across every tracked snapshot — the portfolio value line against your flat cost basis, so unrealised P&L reads as a trajectory rather than just today's number. How to read: the gap between the lines is your gain (value above cost) or loss (below); a rising value line means the basket you hold has appreciated.
